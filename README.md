# odin-rock-paper-scissors

A simple five-round Rock Paper Scissors console game created for The Odin Project.

## How to Play

1. Open `index.html` in a web browser.
2. Open the browser Developer Tools with `F12`.
3. Select the **Console** tab.
4. Enter your choice when the prompt appears.

You can enter any of these choices:

- `1`, `r`, or `rock` for Rock
- `2`, `p`, or `paper` for Paper
- `3`, `s`, or `scissors` for Scissors

The game plays five rounds and prints each round's choices, result, scores, and the final winner in the console. Invalid input is rejected and requested again. Cancelling the prompt counts as Rock.
